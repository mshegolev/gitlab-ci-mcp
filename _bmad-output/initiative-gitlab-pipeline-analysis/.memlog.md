- (requirement) R1: Job artifact listing returns a complete bounded inventory or an explicit structured failure; incomplete responses never become empty or partial success (pipeline-analysis-roadmap.md R1).
- (requirement) R2: CI config lint reports validity, errors, warnings, and bounded merged configuration or generated jobs while clearly distinguishing simulation from execution and deployment (pipeline-analysis-roadmap.md R2).
- (requirement) R3: Pipeline diagnosis exposes job and downstream evidence sufficient to distinguish execution, allowed-failure, retry, queue/resource-wait, and child-pipeline states; unavailable evidence remains unknown (pipeline-analysis-roadmap.md R3).
- (requirement) R4: Test report inspection returns bounded summaries and failed-test details, and distinguishes report artifacts from ordinary archive files (pipeline-analysis-roadmap.md R4).
- (requirement) R5: Deployment history is searchable by environment and status and correlates to pipeline/job/ref/SHA when available, without mutating deployments (pipeline-analysis-roadmap.md R5).
- (requirement) R6: Job logs can be read in bounded ranges with explicit continuation offsets and truncation metadata (pipeline-analysis-roadmap.md R6).
- (constraint) All diagnosis calls remain read-only; none may trigger or retry CI work, play manual jobs, or mutate deployment records (pipeline-analysis-roadmap.md Constraints).
- (constraint) Missing, inaccessible, expired, truncated, and not-requested evidence stay distinct; status alone is not a root-cause diagnosis (pipeline-analysis-roadmap.md Constraints).
- (constraint) Keep project scoping, caller permissions, bounded responses, and secret-handling behavior (pipeline-analysis-roadmap.md Constraints).
- (constraint) No live pipeline/job mutation, workload, deployment, or package release is included in the implementation scope (pipeline-analysis-roadmap.md Constraints).
